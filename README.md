# Restaurant Demo

Ett enkelt React Native-projekt byggt med **Expo** och **React Navigation**.

## Starta projektet

### 1. Klona projektet

```bash
git clone <repository-url>
```

Gå sedan in i projektets mapp:

```bash
cd restaurant-demo
```

### 2. Installera projektets paket

```bash
npm install
```

Detta installerar alla paket som projektet behöver utifrån `package.json`.

### 3. Starta Expo

Start en virtuell mobil i Android Studio. När den virtuella mobilen är igång kan du gå tillbaka till projektet. Starta projektet genom att öppna terminalen och skriv:

```bash
npm run start
```

När Expo har startat visas en QR-kod i terminalen. Skriv sen:

```bash
a
```

för att expo ska hitta din virtuella android mobil.

Du kan sedan köra appen genom exempelvis:

- Android Emulator
- iOS Simulator (macOS)
- **Expo Go** på din mobil

 Om du använder Expo Go kan du skanna QR-koden för att öppna projektet på mobilen.
